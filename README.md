# VRFJ cards

Public image host for job cards posted by **Verified Remote Finance Jobs**
(linkedin.com/company/verified-remote-finance-jobs).

These are the same cards published on the LinkedIn Page - company, role, pay and
apply link. They are public by design: Buffer fetches them anonymously when it
schedules a post, so a private repo returns 401 and the post fails.

**Nothing else goes in this repo.** No candidate profiles, no CVs, no outreach
drafts, no matching matrices. Those live in the private VRFJ repo and are
gitignored there for the same reason.
